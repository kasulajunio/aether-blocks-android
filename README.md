# Aether Blocks v0.1
Prototipo Android original em Java e Canvas, visual 2D estilizado em blocos. Nao utiliza assets de Minecraft.

Joystick para mover, espada para atacar, dash com invulnerabilidade breve, mineracao, construcao com pedra, pocoes, niveis, slimes e um guardiao ao norte. Missao: reunir 8 cristais e derrotar o guardiao. Salva localmente ao pausar e pelo botao Salvar/Ajuda.

Nao e uma recriacao 3D completa. Sem rede, anuncios ou compras. Android 6 ou superior. Assinatura de teste gerada no build; atualizacoes futuras podem exigir reinstalacao e perda do save.

Compilacao e testes publicados no GitHub Actions. Testes de regras nao substituem teste em aparelho Android.
